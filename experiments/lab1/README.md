# Первые эксперименты Reviews Analyzer

Запуск из корня репозитория, Python ≥3.9; baseline не требует сторонних пакетов.

```sh
python3 experiments/lab1/run.py --model rules-v0
python3 experiments/lab1/run.py --model rules-v1
python3 experiments/lab1/run.py --model rules-v1 \
  --dataset experiments/lab1/challenge-v0.1.jsonl \
  --out docs/experiments/results/lab1/challenge
python3 -m unittest discover -s experiments/lab1 -p 'test_*.py' -v
```

Результаты: ответы по каждой записи, JSON-метрики с числителями/знаменателями,
ошибки, дата UTC, SHA-256 входов/runner и окружение.
Исходный golden-v0.1 не изменяется. Baseline настроен на этом наборе;
challenge написан тем же автором и также не является независимым тестом.

Ноутбук: `docs/experiments/lab1.ipynb`; открыть в Jupyter/VS Code, выполнить все
ячейки. Он повторяет baseline в отдельной временной папке, показывает сохранённые
результаты и расчёт бюджета. Сторонние зависимости нужны только интерфейсу Jupyter,
не самим ячейкам. Ноутбук не делает сетевых вызовов.

## Позже: настоящий LLM-прогон

Нужны API-доступ и ключ **в переменной окружения `LAB1_API_KEY`**, не в файле и не
в ячейке. API Яндекса уже проверен чтением каталога моделей; бесплатное покрытие
генерации пока не подтверждено. Подготовленные адаптеры не проверены живыми
запросами; первый запуск сделать на одной записи, проверив формат модели и usage.
Неподдерживаемый JSON-режим — повод поправить адаптер и повторить проверку, не
выдавать текст за корректный JSON. На этой стадии не нужны ответы клиентам.

```sh
# После настройки ключа окружением и прав каталога:
python3 experiments/lab1/run.py --provider yandex \
  --model 'gpt://YOUR_FOLDER_ID/aliceai-llm-flash' \
  --prompt experiments/lab1/prompts/p1.txt --allow-network

# С тем же набором повторить --prompt .../p0.txt
# Gemini — только при официальном доступе в регионе:
python3 experiments/lab1/run.py --provider gemini \
  --model gemini-3.1-flash-lite \
  --prompt experiments/lab1/prompts/p1.txt --allow-network

# Qwen: заранее запущенный пользователем OpenAI-compatible сервер
# на http://127.0.0.1:8001; веса и сервер этот runner не устанавливает.
python3 experiments/lab1/run.py --provider local --model Qwen/Qwen3-8B \
  --prompt experiments/lab1/prompts/p1.txt --allow-network
```

Не передавать облачный ключ локальному серверу: для локального прогона убрать
`LAB1_API_KEY` из окружения. Использовать обезличенные/синтетические данные.
Сетевые прогоны могут тарифицироваться; явный `--allow-network` включает их.
Runner ограничен 20 записями, max output 1200 на запись, timeout 60 с/запрос,
автоповторов нет. Денежного бюджетного контроллера и production deadline здесь нет.
Стоимость LLM в summary остаётся `null`, пока usage не сверены с актуальным тарифом;
пустой usage нельзя принимать за ноль токенов. Сохранение ответов идёт после каждого
вызова, но при ошибке полного summary не будет: такой прогон неполный.

В папке модели/промпта повторный запуск заменяет файлы. Для серии повторов задать
разные `--out` (например `/tmp/lab1-repeat-2`) и сохранить их перед сравнением.
Для статистики минимум три повторения P0/P1, один и тот же набор, версия и настройки.
Температура 0 не гарантирует идентичные ответы провайдера.

## Подключение Яндекса: только бесплатный грант

По предпочтению пользователя от 21.11.2026 платное потребление запрещено.
Новый runner `yandex_trials.py` использует актуальный endpoint
`https://ai.api.cloud.yandex.net/v1/chat/completions`, учёт usage и журнал каждой
попытки. Результаты старых локальных экспериментов сохранены без изменений.

API проверен чтением списка моделей; бесплатный грант не отображался,
поэтому облачная генерация не запускалась. В локальный файл `.env.yandex.local` (игнорируется Git,
права 600) пользователь сохраняет секрет ключа, folder ID и подтверждённые в Billing
значения: `YANDEX_BILLING_STATUS`, `YANDEX_GRANT_REMAINING_RUB`,
`YANDEX_GRANT_EXPIRES` (YYYY-MM-DD). Не пересылать этот файл и не включать в архив.

Runner разрешает запуск только при `TRIAL_ACTIVE`, достаточном остатке и сроке
гранта позже текущей даты; `ACTIVE` не принимается. Это локальная проверка
подтверждённых значений, а не самостоятельный запрос к Billing. Перед каждой
серией статус и остаток проверяются в консоли. Платную версию не включать.

Проверка без сетевого вызова:

```sh
python3 experiments/lab1/yandex_trials.py --check-config
```

После подтверждения бесплатного покрытия и настройки ключа:

```sh
python3 experiments/lab1/yandex_trials.py --smoke --session yandex-smoke \
  --allow-grant-usage --budget-rub 1
python3 experiments/lab1/yandex_trials.py --repeat 3 --session yandex-main \
  --allow-grant-usage --budget-rub 49
```

Предел 1+49 ₽ — максимум расхода средств гранта, не разрешение списания с карты.
При неясном usage/ошибке запрос автоматически не повторяется. Перед новой серией
учесть уже потраченные и зарезервированные суммы из журналов. Свежие сессии не
должны использоваться для обхода общего предела. Опубликованный тариф оценивает
расход без скидки на кеш; фактическое списание гранта сверяется с Billing.

## Бесплатный локальный эксперимент на MacBook

Установка разрешена пользователем после выбора локальной модели. Веса
`mlx-community/Qwen3-4B-4bit`, ревизия
`4dcb3d101c2a062e5c1d4bb173588c54ea6c4d25`, скачиваются в
`.local-llm/models/Qwen3-4B-4bit`; Python 3.12 и библиотеки — в `.local-llm/`.
Эта папка исключена из Git и архивов сдачи. Нет установки системной службы:
после завершения Python-процесса модель не продолжает работать в фоне.

Для воспроизведения на Apple Silicon создать Python 3.12 venv и установить
версии из `requirements-local.lock.txt`. Зафиксированное окружение включает
MLX/Metal; оно предназначено для macOS arm64, а не Linux/Windows.
Скачать snapshot указанной ревизии через `huggingface_hub.snapshot_download`,
сохранить ревизию в `.local-llm/model-revision.txt`. Лицензия модели Apache-2.0
указана в [карточке конвертации](https://huggingface.co/mlx-community/Qwen3-4B-4bit).
Используется локальный Safetensors, `trust_remote_code=False`.

```sh
.local-llm/venv/bin/python experiments/lab1/local_trials.py \
  --smoke --session local-qwen3-4b-smoke
.local-llm/venv/bin/python experiments/lab1/local_trials.py \
  --repeat 3 --session local-qwen3-4b-pilot
```

Runner сам включает offline-режим Hugging Face/Transformers. Во время генерации
нет обращений к Яндексу или другим облачным LLM. Загружается одна модель,
используются P0/P1, greedy decoding (temperature=0), seed=0,
`enable_thinking=False`, максимум 800 выходных токенов на отзыв.
Невалидный JSON не исправляется и не извлекается из Markdown; обрыв по лимиту
также считается ошибкой. Сохраняются сырой ответ, фактические токены, время,
finish_reason и пик памяти MLX. Пик MLX не равен всей RAM системы.
Каждый запуск требует новое имя сессии, чтобы не перезаписывать доказательства.

Для лабораторной считаем только **стоимость облачного API = 0 ₽**. Электричество
и амортизация MacBook не измерены. Локальные результаты не доказывают скорость
или качество Alice/Gemini и не являются тестом всего приложения на 100 отзывах.
