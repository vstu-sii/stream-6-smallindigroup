# Кандидаты моделей и токен-бюджет

Евгений Агарков · AI Engineer · лабораторная № 1 · 21.11.2026.

**Сравнение кандидатов + локальный пилот.** Облачные модели сопоставлены по документации;
на Qwen3-4B-4bit выполнены реальные P0/P1/P2-пробы. Сравнения точности между
разными семействами моделей пока нет.
Приоритет — доступность, русский текст, извлечение JSON, проверяемость цитат,
стоимость полного пакета. Качество, latency и стабильность требуют эксперимента.

## 1. Три кандидата

| Кандидат | Где запускается | Что подтверждено источником | Что ещё не проверено |
|---|---|---|---|
| Alice AI LLM Flash | Yandex AI Studio, РФ | URI `gpt://<folder>/aliceai-llm-flash`, контекст 65 536, OpenAI-compatible API [M1] | Доступ команды, поддержка выбранного JSON-режима, качество на наших отзывах, реальные токены/скорость |
| Gemini 3.1 Flash-Lite | Gemini Developer API | ID `gemini-3.1-flash-lite`, опубликованный тариф [M3]; общий механизм structured output [S6 в research] | Доступ в официально поддерживаемом регионе, ключ и биллинг, конкретные ответы/квоты |
| Qwen3: локальный вариант | MacBook, MLX | Для экспериментов выбран Qwen3-4B-4bit: около 2,28 GB файлов модели, Apache-2.0 [M7]. Первоначально также рассматривался 8B [M5] | 4B фактически проверен: [метрики](experiments/local-results.md); 8B и другие режимы не запускались |

YandexGPT Lite **не выбран**: официально отключён 15.11.2026 [M2]. Наличие старых
цен в поисковой выдаче не доказывает доступность модели. Размер контекста сам по
себе не доказывает пригодность к нашему разбору. Это ограниченный shortlist,
а не заявление, что выбраны три лучших модели на рынке.

## 2. Стоимость

Тарифы проверены 21.11.2026. Yandex — синхронная генерация, рубли с НДС;
Gemini — Standard paid, USD за 1 млн токенов. Кеш и скидки не предполагаются.

| Модель | Вход | Выход | Расчётный пакет: 42 000 вход + 24 000 выход | С одним полным повтором |
|---|---:|---:|---:|---:|
| Alice AI LLM Flash [M4] | 0,10 ₽ / 1000 | 0,20 ₽ / 1000 | **9,00 ₽** | **18,00 ₽** |
| Gemini 3.1 Flash-Lite [M3] | $0,25 / 1 млн | $1,50 / 1 млн | **$0,0465** | **$0,0930** |
| Qwen3-8B локально | Нет оплаты API за токены | Нет оплаты API за токены | Не определена: нужны тариф оборудования и время | Измерить; «бесплатной» модель не считаем |

Для Gemini: при **условном**, не текущем биржевом курсе 100 ₽/$ получается 4,65 ₽,
с повтором 9,30 ₽. При 80–120 ₽/$ диапазон 3,72–5,58 ₽, с повтором 7,44–11,16 ₽.
Банковские комиссии/налоги и условия аккаунта требуют отдельной проверки.
Не сравнивать эту оценку с рублёвым счётом как окончательную цену.

Формула: `C = T_in × P_in + T_out × P_out`, включая каждую попытку.
Для локального варианта `C = цена_часа × время_сек / 3600 + прочие расходы`.
Допустимая цена часа при 180 сек и пределе 50 ₽ — ≤1000 ₽/час без прочих затрат;
это порог, не найденное предложение хостинга.

## 3. Откуда взялись 42k/24k: план, не измерение токенизатором

Предлагаем 10 порций по 10 отзывов. Для одной порции предполагаем:

- Системная инструкция/таксономия/схема: 1200 входных токенов.
- 10 отзывов и их поля: 3000 входных токенов (в среднем 300 на отзыв).
- JSON-результаты: лимит 2400 выходных токенов на порцию.

Итого: `10 × (1200 + 3000) = 42 000` вход, `10 × 2400 = 24 000` выход.
Итоговый отчёт строится кодом и шаблонами; дополнительной генерации нет.
Если появится LLM-сводка/генерация действий, её токены надо прибавить.
Для длинных цитат и множества проблем 2400 может не хватить: truncation считается
ошибкой, а не «отсутствием проблем»; порции уменьшаются, бюджет пересчитывается.

Чувствительность для Alice: если на отзывы уйдёт 100k входных токенов + 12k
инструкций, при 24k выхода оценка `112×0,1 + 24×0,2 = 16 ₽`, полный повтор — 32 ₽.
Это арифметический сценарий, не гарантия обработки произвольно длинного CSV.
В PRD ограничено число строк, но не длина текста: до реализации согласовать
ограничение входных токенов/длины и понятный отказ при превышении.

До приёмки нужны фактические usage провайдера, токенизация реального пакета,
все оплаченные повторные обращения и полный замер wall-clock. Скрытые reasoning
токены, если они тарифицируются, также входят в расход. Лимит 50 ₽ пока не доказан.

## 4. Латентность и деградация

При последовательных 10 порциях и 10 секундах на валидацию/агрегацию остаётся
170 секунд: средний вызов должен укладываться в 17 секунд. Это производный бюджет,
не измеренная скорость модели. Параллелизм возможен только после проверки квот.
Полный пакет 100 отзывов ещё не прогонялся; p95 локальных правил к LLM неприменим.

План приложения: до запуска резервировать бюджет, deadline 180 секунд на пакет,
один повтор максимум, прекращать новые вызовы при исчерпании резерва. Не переключать
модель незаметно: другой кандидат должен отдельно пройти evals. При недоступности
вернуть понятный отказ; не заменять анализ заведомо слабым baseline без объяснения.
Пилотный runner обрабатывает ≤20 записей, без ретраев, по одному отзыву. Это иной
сценарий, предназначенный для сравнения промптов; лимиты production он не реализует.

## 5. Если модель держим локально

Для Qwen3-8B только веса BF16 требуют примерно `8,2B × 2 ≈16,4 GB` (около 15,3 GiB),
4-bit — теоретически ≈4,1 GB; реальная память выше из-за служебных данных и KV cache.
Это расчёт нижней границы, не рекомендация покупать определённое железо.
Контекст/размер порции уменьшать до измеренного доступного объёма памяти.

Локально отзывы могут не уходить внешнему провайдеру, если отключены внешние вызовы
и аккуратно настроены логи. Добавляются загрузка весов, обновления, сервер,
ограничение конкурентности и повторный eval после квантования. Нельзя автоматически
переносить качество полноточной модели на 4-bit. Для первых проб фактически установлен меньший Qwen3-4B-4bit: файлы модели 2,28 GB,
изолированная установка вместе с Python/MLX около 3,3 GB. В P2 пик памяти MLX
около 3,24 GB; это не вся RAM системы. 8B остаётся непротестированной альтернативой.

## 6. Порядок выбора и незакрытые вопросы

Исходный план — начать с Alice Flash. API подключён (список моделей: HTTP 200),
но пользователь разрешил только бесплатное использование, а грант в аккаунте
не отображался. Поэтому генерация в Яндексе не запускалась. Для лабораторной
фактически выбран локальный Qwen3-4B-4bit; это выбор доступности для эксперимента,
не доказательство превосходства над облачными моделями.
Gemini — сравнительный кандидат при легитимной доступности API; официальный список
регионов нужно сверить с местом работы команды [M6]. Qwen — вариант при требовании
локальности и подтверждённом железе.

Для каждого кандидата: одни входы, P0/P1, одинаковые параметры где поддерживаются,
сохранённые ответы, usage, время, ошибки, версия модели. Перед переносом в приложение
нужен независимый набор Quality с `platform/product_id/review_id` и примерами разных
зон ответственности в одном отзыве. Финальный выбор по качеству **открыт**.

## Фактический пилот: Qwen3-4B-4bit

[Полные таблицы](experiments/local-results.md): P2 дал 83,3% precision / 83,3% recall
на 12 golden-примерах, 100% валидности схемы, но только 8/12 дословных цитат и 0/1
critical. На 8 challenge-примерах precision 66,7%, recall 80%, critical 0/1.
Значит, увеличение промпта не делает модель готовой к продуктовой приёмке.

Реально измерены токены, время и память каждого вызова; стоимость облачных API — 0 ₽.
Среднее время одного отзыва в P2 умноженное на 100 даёт только грубый ориентир
и не подтверждает предел 180 секунд: приложение, агрегация и полноценный пакет
не запускались. Нужны оптимизация порций/контракта и повторный замер.
