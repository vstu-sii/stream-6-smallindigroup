# Общий словарь Reviews Analyzer

Единые определения для требований, интерфейса, анализа отзывов и эталонных примеров.

| Термин | Что означает в нашем проекте |
|---|---|
| Сегмент | Выбранная группа пользователей с похожим процессом: небольшие продавцы одежды, тканей и текстиля на маркетплейсах, которые сами разбирают отзывы |
| Продавец | Пользователь продукта, принимающий решение о проверке товара, изменении описания или обращении к площадке; это не автор покупательского отзыва |
| Маркетплейс | Торговая площадка: Wildberries, Ozon или Яндекс Маркет; во входе — `platform` |
| Товарная позиция | Конкретный товар в магазине, по которому отдельно собираются и считаются проблемы; во входе — `product_id` вместе с `platform`, чтобы различать товары разных площадок |
| Отзыв | Один текст покупателя с идентификатором, оценкой и привязкой к площадке и товару; во входе — `platform`, `review_id`, `rating`, `text` |
| Пакет отзывов | Набор, который пользователь загружает и обрабатывает за один раз; в первой версии — до 100 отзывов |
| CSV | Текстовый формат таблицы; в нашем входном файле одна строка соответствует одному отзыву |
| Проблема | Описанный в отзыве недостаток или затруднение, которое нужно показать пользователю; один отзыв может содержать несколько проблем |
| Код проблемы | Устойчивое техническое имя типа проблемы; `problems[].code`, например `material_quality` |
| Таксономия | Словарь кодов проблем и правил, по которым жалоба относится к определённому типу |
| Перефраз | Другая формулировка той же проблемы: например, «село после стирки» и «стало меньше после машинки» |
| Группировка | Объединение перефраз одной проблемы внутри одной товарной позиции с учётом площадки; жалобы на разные товары не смешиваются |
| Упоминание проблемы | Один отзыв, в котором найден конкретный код проблемы; повтор одной жалобы внутри текста не увеличивает её счётчик |
| Частота проблемы | Число разных отзывов с проблемой; доля равна этому числу, делённому на число принятых для анализа отзывов того же товара на той же площадке |
| Цитата / улика | Фрагмент исходного отзыва, которым подтверждается вывод; техническое поле — `evidence`. Выдуманный или изменённый текст не считается цитатой |
| Серьёзность | Тяжесть описанных последствий; `severity`: `none`, `low`, `medium`, `high`, `critical` |
| Критический сигнал | Указание в тексте на возможные особо тяжёлые последствия; показывается человеку отдельно и не является доказательством вреда |
| Приоритет | Порядок проблем в отчёте: сначала более серьёзные, затем более частые внутри уровня серьёзности |
| Зона ответственности | Предположение о том, кто может влиять на устранение причины: продавец или площадка; `owner`: `seller`, `marketplace`, `null` при неопределённости. Это не установление вины |
| Подозрительный отзыв | Отзыв с признаками, требующими проверки; `suspicious`. Пометка не доказывает накрутку и не исключает отзыв автоматически |
| Отчёт | Результат разбора: проблемы по товарам, частота, серьёзность, цитаты, зона ответственности и подсказки действий |
| Действие | Выбранный человеком конкретный следующий шаг, связанный с подтверждённой проблемой; например, проверить размер образца после стирки |
| MVP | Первая ограниченная работающая версия: загрузка файла и отчёт. Интеграции и публикация ответов в неё не входят |
| North Star | Главная метрика учебного проекта: доля заданий, в которых участник команды или однокурсник за 10 минут выбрал обоснованное действие по отчёту; цель — не ниже 80%. Она оценивает выполнение сценария, а не спрос продавцов |
| Golden dataset | Версия набора отзывов с заранее подготовленными правильными ответами для проверки системы; владелец — Quality |
| Эталон | Ожидаемый результат для конкретного проверочного примера, поле `expected`; он определяется до прогона системы |
| Полнота / recall | Доля найденных верных пар «отзыв, код проблемы» среди всех эталонных пар; цель — не ниже 85% |
| Точность / precision | Доля верных пар «отзыв, код проблемы» среди всех пар, которые выдала система; цель — не ниже 80% |
| Запрос и его стоимость | Одна полная операция анализа пакета. Для контрольного пакета 100 отзывов сумма всех обращений к модели, включая повторы, ограничена 50 ₽ |
| Инъекция инструкций | Попытка автора отзыва управлять системой текстом вроде «игнорируй правила»; такой текст остаётся данными и не выполняется как команда |

Новые коды и изменения значений обсуждаются Product, Quality и AI Engineer до изменения эталонов и реализации.
