# Lab1: AI Engineer — Initiation Deliverables

Для Reviews Analyzer подготовлены исследование со ссылками, сравнение облачного,
российского и локального кандидатов, токен-бюджет и ADR выбора подхода.
Реальные локальные пробы Qwen3-4B-4bit показывают, как промпт влияет на разбор
отзывов: P2 исправил тип JSON null, но не устранил ошибки цитат и пропуски critical.
Модель не объявляется готовой к продуктовой приёмке.

Материалы:

- [Исследование и ADR](../research.md).
- [Кандидаты и бюджет](../model-candidates.md).
- [Записка об экспериментах](lab1.md), [таблицы](local-results.md), [ноутбук](lab1.ipynb).
- Код запуска, три версии промптов, фиксированные зависимости и сырые ответы
  находятся в `experiments/lab1/` и `docs/experiments/results/lab1/`.

Проверено: 180 основных локальных генераций и один smoke, по три повтора каждого
промпта на 20 синтетических отзывах; пересчёт метрик по ответам; 15 тестов evaluator,
бюджета и ограничения бесплатного режима; все шесть кодовых ячеек ноутбука выполнены.
Облачная генерация не выполнялась, расход облачного API — 0 ₽.

Ограничения: данные использованы при разработке; независимого holdout нет.
Группировка внутри товара, пакет 100 отзывов и North Star не проверялись.
Ключи API, веса модели и локальное Python-окружение исключены из Git/пакета сдачи.

Перед сдачей автору нужно прочитать исследование и источники, ознакомиться с
ошибками и подготовиться объяснить выбор подхода и его цену своими словами.
