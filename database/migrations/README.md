# Миграции PostgreSQL

Начальная миграция [001_baseline.sql](001_baseline.sql) подключает [schema.sql](../schema.sql). Для пустой базы её можно запустить командой `psql -d reviews_dev -f database/migrations/001_baseline.sql`. Compose применяет ту же схему при создании нового тома. Изменения после начальной версии кладём сюда отдельными SQL-файлами в порядке применения, начиная с `002_*.sql`. При переходе к лабе 3 нужно добавить учёт применённых версий и проверку обновления существующей базы.

Отзыв уникален по паре `(platform, external_id)`. `batch_reviews` сохраняет версию исходного текста, оценку и дату, полученные в конкретном пакете. Составные внешние ключи привязывают цитату к тому же пакету и товару, что и группа проблем. Воркер проверяет дословность цитаты по позициям в исходном тексте. Частота считается по разным отзывам группы, доля — от всех принятых отзывов о товаре в пакете. API проверяет лимит в 100 строк перед созданием задания.
